# Henna by Kushangi 🌿✨

Luxury bridal mehndi and bespoke henna artistry website designed with refined typography, botanical flourishes, and an editorial wedding aesthetic.

![Henna by Kushangi](https://images.unsplash.com/photo-1610030469983-98e550d6193c?auto=format&fit=crop&w=1200&q=80)

---

## ✨ Features

- **Luxury Indian Aesthetic**: Warm sandstone (`#FDFBF7`), aged henna tones (`#633928`), antique gold (`#C5A059`), and eucalyptus accents (`#3E4D35`).
- **Interactive Storytelling**:
  - Animated calligraphy opening intro
  - Editorial Hero banner with delicate floral frame accents
  - Philosophy & natural botanical henna details ("The Art of Henna")
  - Asymmetric curated portfolio ("Our Mehndi Stories") with high-resolution lightbox zoom
  - Bespoke bridal couture showcase ("Made for Your Moment")
  - Client celebrations & testimonials
  - Direct WhatsApp booking & Instagram integration
- **Responsive & Lightweight**: Built with React 19, Tailwind CSS v4, and Motion.

## 🚀 Quick Start (Local Development)

### 1. Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (v18 or higher recommended).

### 2. Clone the Repository
```bash
git clone https://github.com/<YOUR-USERNAME>/henna-by-kushangi.git
cd henna-by-kushangi
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Start Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:3000` (or the port indicated in terminal).

### 5. Build for Production
```bash
npm run build
```
The production bundle will be generated in the `dist/` directory.

## 🌐 1-Click Free Deployment

### Deploy to Vercel
1. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New Project"** and select your `henna-by-kushangi` repository.
3. Keep default settings (Framework: Vite, Build command: `npm run build`, Output directory: `dist`).
4. Click **Deploy**. Your custom link will be live in seconds!

### Deploy to Netlify
1. Go to [netlify.com](https://netlify.com) and log in with GitHub.
2. Click **"Add new site"** > **"Import an existing project"**.
3. Select this repository and click **Deploy site**.
